# EliteCam (Redmi Note 11)

CameraX app with live scene detection and scene-adaptive enhancement.

## Build
1. Install Android Studio (Koala or newer). File > Open > select this folder.
2. Let Gradle sync (needs internet). If asked about the Gradle wrapper, accept.
3. Phone: Settings > About phone > tap MIUI version 7x > then Additional settings > Developer options > USB debugging ON.
4. Plug in the phone, press Run. Or Build > Build APK(s) to get an installable file.

## What it does
- Live label: Low light / High contrast / Bright / Balanced + warm/cool cast
- Auto exposure compensation per scene
- Max-quality capture with hardware high-quality noise reduction and edge mode
- Post-process: white balance, levels, gamma, shadow lift, highlight recovery, S-curve, saturation, sharpen/denoise
- Saves original (_orig) and enhanced to Pictures/EliteCam
- Tap to focus, pinch to zoom
